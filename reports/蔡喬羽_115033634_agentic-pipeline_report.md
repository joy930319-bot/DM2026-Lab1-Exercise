## 1. Dataset Loading

I used `load_dataset_tool` to load four categories from the 20 Newsgroups dataset: `alt.atheism`, `soc.religion.christian`, `comp.graphics`, and `sci.med`. The tool returned `load_dataset_1`, containing 2,257 documents. The category counts were 480, 599, 584, and 594, respectively. This dataset served as the input for subsequent text analysis.
